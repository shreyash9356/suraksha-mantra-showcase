# Suraksha Mantra

### Student Cyber Awareness Portal

**Developed for Chandrapur Police Department, Maharashtra**

## Overview

Suraksha Mantra is a student-focused cyber awareness portal developed to promote cybersecurity awareness among students and provide accessible educational resources on cyber safety. The platform combines learning materials, interactive quizzes, and certificate generation in a single web-based portal.

## Key Features

- Student Registration & Login
- Cybersecurity Awareness E-Book
- Interactive Cyber Awareness Quiz
- 20-question assessment
- Automatic score calculation
- Certificate generation
- Student result tracking
- English / Marathi language support
- Responsive mobile-friendly interface
- Administrative management panel

## Technology Stack

**Frontend:** React.js, Vite, Bootstrap 5

**Backend:** Python, Django, Django REST Framework

**Database:** PostgreSQL

**Authentication:** JWT

**Deployment:** Production web deployment

## System Architecture

The portal follows a client-server architecture:

**React Frontend → REST API → Django Backend → PostgreSQL Database**

The frontend handles the user interface and interactions, while the Django REST API manages authentication, application logic, quiz processing, certificate generation, and database operations.
